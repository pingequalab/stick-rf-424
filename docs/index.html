FAQ

Which firmware version should I use?

Use the latest Bruce beta. Do NOT use v1.13 stable — it has a known SPI timing bug causing CC1101 NOT FOUND on M5StickC Plus 1.1. Flash at bruce.computer/flasher.

Why do I see "CC1101 NOT FOUND"?

Bruce v1.13 stable has a known SPI bus timing issue on M5StickC Plus 1.1. Flash the latest Bruce beta, which includes critical patches for SPI initialization and AXP2101 power management.

How do I switch between CC1101 and nRF24?

Use the physical slide switch on the board. Slide to 433MHz for CC1101, or 2.4GHz for nRF24L01+. Then select the corresponding Legacy module in Bruce.

Why use the "Legacy" setting in Bruce?

The Legacy setting ensures zero-latency module detection on M5StickC Plus hardware. Always choose CC1101 (Legacy) or NRF24 (Legacy) when using this module.

Does it work with M5Stack Cardputer?

No. Stick RF 424 is for M5StickC Plus 1.1 and 2. For Cardputer, see the Hydra RF series. For StickS3, see RF PACK S3.

Is soldering required?

No. Stick RF 424 connects via GPIO header — completely solderless.

What Sub-GHz frequencies are supported?

315 MHz, 433 MHz, 868 MHz, and 915 MHz via the CC1101 chipset.
